- **feat(cli-tools):** Gemini CLI can be pointed at the gateway, via a new origin-form base placeholder. `{{baseOrigin}}` renders the gateway origin with no `/v1` suffix, for clients that append their own versioned path; Gemini CLI uses it with `GOOGLE_GEMINI_BASE_URL` + `GEMINI_API_KEY`. `@google/genai` composes `{origin}/v1beta/models/{model}:generateContent`, which this app already serves and already authenticates via `x-goog-api-key`. Both base-URL forms now come from one helper so they cannot drift ([#60](https://github.com/LMPrado-DZ23/OmniRoute/pull/60))
