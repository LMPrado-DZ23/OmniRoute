- **feat(routing):** a request can state how long it is willing to wait. `X-OmniRoute-Latency-Budget: <ms>` binds every router strategy: a candidate whose p95 estimate exceeds the budget is excluded from selection **and dropped from the failover chain** rather than merely moved last, is reported as `latency_over_budget` on the recorded decision, and a request with nothing left inside the budget gets a 503 that names it. The budget is per attempt, not cumulative. Without the header, routing is byte-identical to before ([#53](https://github.com/LMPrado-DZ23/OmniRoute/pull/53))
