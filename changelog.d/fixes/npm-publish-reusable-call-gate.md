- **fix(ci):** the npm publish gate could be walked around through the front door. `github.event_name` inside a reusable workflow is the **caller's** event, so dispatching any workflow that calls `npm-publish.yml` reported `workflow_dispatch` in the gate and inherited the "a human asked for this" exemption — reaching a provenance-signed publish of `omniroute`, a package name upstream owns, without `ENABLE_NPM_PUBLISH` ever being set. `electron-release.yml` carries its own `ENABLE_NPM_PUBLISH` guard, so nothing was reachable in practice; a gate whose correctness rests on an `if:` in another file is not a gate. The exemption now also requires `github.job_workflow_ref` to be empty, which is true only when this workflow is the one that was dispatched, and the refusal says which of the two cases it refused so the next reader does not re-add the shortcut. Guarded by 6 tests, including one that fails on an unqualified `workflow_dispatch` test.
