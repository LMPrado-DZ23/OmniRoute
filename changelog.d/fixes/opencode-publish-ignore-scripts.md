- **fix(ci):** the two jobs that publish `@omniroute/opencode-plugin` and `@omniroute/opencode-plugin-v2` installed their dependencies with `npm install --no-audit --no-fund` — no `--ignore-scripts` — while holding `id-token: write` and ending in `npm publish --provenance`. Any `postinstall` in either plugin's dependency tree therefore ran with the provenance token in scope, and `install` (rather than `ci`) also let a drifted lockfile resolve a tree other than the reviewed one. Both are now `npm ci --ignore-scripts --no-audit --no-fund`; the auto-bump step immediately before uses `npm version --no-git-tag-version`, which updates the lockfile too, so `ci` stays in sync with it. The plugin CI workflow's three installs were changed the same way, so if skipping dependency scripts ever breaks a build it breaks on a PR instead of inside the job that holds the token. Verified locally for both packages: `npm ci --ignore-scripts` → `npm run build` → `npm test` gives 366/367 (1 pre-existing skip) and 219/219, and `npm version patch --no-git-tag-version` followed by `npm ci` installs cleanly.
