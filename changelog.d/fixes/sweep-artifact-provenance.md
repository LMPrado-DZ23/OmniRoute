- **fix(ci):** the Release-Green sweep's artifact gate could not pass even on a good build. Once the aggregator had swap (run 36200666574) its `next build` finished in about 8.5 minutes — no more `exit 143` — and the gate then failed `Build provenance check failed`, for two reasons that belong to the workflow, not to the release line: `check:pack-artifact`'s own fallback runs `build:cli`, which never writes `dist/BUILD_SHA` (only `build:release` does), and the provenance guard (#10427) defaults to ancestry against `origin/main`, which a `release/v*` line is not an ancestor of. The aggregator now runs `npm run build:release` (after swap, before the gates, never on `--quick`) so the gate finds a complete stamped `dist/`, and passes `OMNIROUTE_RELEASE_REF=origin/<branch under test>`, the same thing `ci.yml` does for pull requests. Pinned by a workflow test on the step's order, its condition and the env value.
