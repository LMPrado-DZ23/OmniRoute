- **fix(ci):** the Release-Green sweep threw away a complete report to die at exit 143. `check:pack-artifact` falls back to a full `next build`, which the hosted runner cannot fit — `build.yml` has been manual-only since #11946 for exactly that reason (19 of 30 runs killed with "the runner has received a shutdown signal", VM out of memory). Both sweeps on 2026-09-20 died there roughly six minutes in, silently, taking **thirteen green gates and seven green suites** with them. On a hosted runner the artifact gate is no longer attempted; it is **recorded as unmeasured**, which is a HARD failure carrying the reason and the remedy, because a sweep missing a required gate is not release-green and must not read as if it were. When `USE_VPS_RUNNER` selects a runner the build actually fits, the gate runs exactly as before. New `--unmeasured=<id>:<reason>` states a gate this environment cannot run; a malformed value throws rather than recording nothing, which would be the silent omission the flag exists to prevent.
