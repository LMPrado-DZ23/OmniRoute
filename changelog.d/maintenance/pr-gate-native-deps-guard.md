- **ci:** `check:native-deps` now runs in the PR gate instead of only inside a full build. The guard fails when an optional package the build needs was silently dropped by `npm ci`, but it was wired only as `prebuild` — i.e. inside a `next build` that no PR job executes and that no available runner can complete. So when the runner's npm began enforcing `allowScripts`, dropped `@huggingface/transformers` (its dependency `onnxruntime-node` carries the install script) and exited 0, nothing reported it until the v3.8.55 tag's installer build failed and the release had to be re-tagged. The script is a cheap Node check over the installed tree, so it now runs as the step directly after the install in `fast-gates`, where a lockfile-only PR (which the change classifier counts as code) would have tripped it five days earlier. A test pins that it stays there, immediately after the install, as a hard gate.
