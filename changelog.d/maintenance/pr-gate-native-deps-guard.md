- **ci:** `check:native-deps` now runs in the PR gate instead of only inside a full build. The guard fails when an optional package the build needs was silently dropped by `npm ci`, but it was wired only as `prebuild` — i.e. inside a `next build` that no PR job executes. So when the runner's npm began enforcing `allowScripts`, dropped `@huggingface/transformers` (its dependency `onnxruntime-node` carries the install script) and exited 0, nothing reported it until the v3.8.55 tag's installer build failed and the release had to be re-tagged. The script is a cheap Node check over the installed tree, so it is now the first entry of the aggregated gate list in `fast-gates`, where a lockfile-only PR (which the change classifier counts as code) would have tripped it five days earlier. It lives **inside** that non-fail-fast loop rather than as a step of its own: a standalone gate step that can fail aborts the job and reports every later gate as skipped, the #8542 mechanism `repro-8542.test.ts` forbids — the first version of this change was a standalone step and that test rejected it. A test pins that it stays first in the list and never becomes a separate step.
